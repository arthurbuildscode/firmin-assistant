# content/ — ce que l'assistant sait et dit

- `CLAUDE.md` : la personnalité et les règles de l'assistant, injectées à chaque message par le bot (`--append-system-prompt-file`). C'est le seul fichier à modifier pour changer le ton : éditer la section « Ton » (et « Contexte Telegram » pour la longueur), relancer `/nouveau` dans Telegram pour que la session suivante le prenne en compte. Pas besoin de redémarrer le bot.
- `onboarding/NN-nom.md` : un module de découverte = un fichier. Pour en ajouter un, copier `20-echeances.md`, choisir un numéro libre (ordre de proposition), garder les sections « Objectif, Déclencheur, Déroulé, Questions exactes, Où écrire, Message de clôture, Ce qu'il ne faut pas faire », cinq questions max, et ne viser que les chemins autorisés de `data/` (foyer, personnes, alimentation) ou les outils `echeances_*` / `anniversaires_*`. Le nom du fichier sans `.md` est l'identifiant passé à `onboarding_terminer`.
- Pour qu'un nouveau module soit proposé, ajouter une ligne dans la section « Onboarding » de `CLAUDE.md` indiquant quand le déclencher ; l'assistant lit le fichier du module avec `Read` avant de le mener.
- `prompts/*.md` : prompts des tâches programmées, exécutés avec `claude --bare -p` donc **sans** `CLAUDE.md` ; chacun rappelle l'identité et le ton en tête. Les données arrivent en JSON entre `<donnees>…</donnees>`, injectées par `tools/runner.py`. Pour changer un brief, modifier la section « Structure » du prompt concerné.
- Convention `{{assistant.nom}}` : partout dans `content/`, ce jeton est remplacé au lancement par la valeur de `assistant.nom` dans `data/config.yaml` (par le bot pour `CLAUDE.md`, par `runner.py` pour les prompts). Ne jamais écrire le prénom en dur ; pour le changer, éditer `config.yaml` puis relancer le bot.
- Tutoiement par défaut : réglable dans `data/foyer/regles.md` (l'assistant le lit), pas dans `content/`.
- Règle d'or pour tout texte ici : français, pas de jargon technique dans ce que l'assistant dit aux utilisateurs, noms d'outils exacts du `CONTRACT.md` §6, aucune donnée réelle (prénoms d'enfants, adresses, dates de naissance).
- Pour tester un changement de prompt sans attendre le cron : `/brief` dans Telegram lance le brief du jour à la demande.
